# Лабораторная работа №3 — Git Branches

## Краткое описание
Учебный веб-проект из предыдущей лабораторной работы. Проект демонстрирует работу с HTML, CSS, JavaScript и Git-ветками.

## Настройка разработки
1. Установить Git и Visual Studio Code.
2. Открыть папку проекта в Visual Studio Code.
3. Для просмотра сайта открыть `index.html` в браузере.
4. Для работы с Git использовать терминал VS Code.

## Структура веток
- `main` — готовая протестированная версия.
- `develop` — интеграционная ветка.
- `feature/*` — отдельные ветки для разработки функций.

Дополнительные правила работы с Git описаны в файле [GIT_GUIDE.md](GIT_GUIDE.md).
