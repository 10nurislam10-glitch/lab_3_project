# Git Guide

Основные правила лабораторной работы:

- Репозиторий создаётся командой `git init -b develop`.
- Автор и email Git должны быть настроены.
- Для `main` и `develop` используется слияние без fast-forward (`--no-ff`).
- `main` содержит готовую версию и получает изменения только через merge из `develop`.
- `develop` используется для интеграции feature-веток и обновления `CHANGELOG.md`.
- Feature-ветки создаются из `develop` и называются `feature/<descriptive-feature-name>`.
- В имени ветки слова разделяются знаком `-`, длина имени — не более 80 символов.
- Сообщения коммитов оформляются по правилам предыдущей лабораторной работы: `<type>: <short summary>`.
