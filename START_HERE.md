# Как открыть и проверить ЛР3

1. Распакуйте ZIP.
2. Откройте папку `lab_3_project` в Visual Studio Code.
3. Откройте терминал VS Code.
4. Проверьте ветки:

```bash
git branch -a
```

5. Посмотрите историю:

```bash
git log --oneline --graph --decorate --all
```

6. Проверьте тег:

```bash
git tag
```

В проекте уже подготовлена история Git с ветками `main`, `develop` и `feature/*`.
